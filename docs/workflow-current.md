# Current direct workflow

1. Receive original feedback and immutable images, pin project/repository and serialize the project lane.
2. Luna makes one preliminary classification using bounded MD/verified memory. This never grants edit or release permissions.
3. Codex surveys the pinned checkout/MD/images, then resumes the exact saved thread for authorized implementation. Low/medium follow configured automation; high or indispensable product decisions retain consent gates. Scope, base, library and worktree remain bound.
4. Codex updates source/tests/necessary MD. Updated MD and unchanged reference MD are separate fields. Supervisor independently runs the project code check, validates scope and commits.
5. Retain failed checks. Supported retries queue a no-AI exact-commit recheck. For a reported repaired inline offline harness, independently run committed OFFLINE-labelled specs (only changed approved specs), with no web server and an unavailable browser executable. Require at least one test, all passed, no skips/errors, plus code/diff checks before archiving the old failure. Never execute model-provided heredoc text or infer success from a summary/build alone. Other unsupported failures remain blockers.
6. Push a draft PR and collect exact-head GitHub CI. Code-only policy still requires writer-check and non-browser checks; browser jobs are explicitly skipped, never labelled visually verified.
7. Under existing consent, merge the verified head and wait for Railway success on the merge commit. A local result, green build or merged PR alone is not completion. Optional HTTP check is separate.
8. Sync the library to the released commit and retain verified outcome/MD provenance; release the project lane for the next feedback.

Recheck v3 is bounded to three attempts, preserves original failed checks/commit/revision and has a separate claim. Empty/skipped offline tests, source mutation, changed HEAD, stale revision or overlapping work cannot certify success. Restart recovery only queues independently verifiable reported retries, never another paid model call.
